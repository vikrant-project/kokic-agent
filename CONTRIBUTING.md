# Contributing

1. Open an issue describing the problem or proposed change without private account data.
2. Create a focused branch and keep changes scoped.
3. Run the Python suite and JavaScript checks documented in the README.
4. Include a brief explanation of behavior, validation and any limitations in your pull request.

Use temporary accounts and runtime directories for testing. Never include your local database, profiles, provider tokens, real login credentials or account screenshots in a contribution. Include third-party license notices when adding dependencies.
